Time and Space Complexity

Time complexity is a measure used in computer science to evaluate how the runtime of an algorithm scales with the size of the input. Writing an efficient algorithm requires minimizing this runtime so that the program can handle large datasets gracefully.

Space Complexity refers to the total amount of memory or storage an algorithm needs to execute and complete its task. For example, if an algorithm requires memory that scales linearly with the input data size, it is said to have a space complexity of O(n).
